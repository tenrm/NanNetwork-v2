# Nan Network v2 · แผนภาพเครือข่ายศูนย์เรียนรู้น่าน

**เปิดใช้งาน:** https://tenrm.github.io/NanNetwork-v2/ · เวอร์ชันเดิม (วงเดียว 3 ชั้น) ยังเปิดได้ที่ https://tenrm.github.io/NanNetwork/

## มีอะไรใหม่ใน v2
- **มุมมอง "แผนที่น่าน"** (เพิ่ม 26 พ.ย. 2569): วางหน่วยงานบนแผนที่ขอบเขตอำเภอ/ตำบลของน่าน แล้ววาดเส้นเครือข่ายทับ
  - ตำแหน่งโดยประมาณ: ศูนย์กลางตำบล (ถ้าช่อง "พื้นที่" หรือชื่อมี ต./ตำบล) → ที่ตั้งอำเภอ (อ./อำเภอ หรือชื่ออำเภอในชื่อหน่วยงาน) → ตัวเมืองน่าน (หน่วยงานระดับจังหวัด) → กล่อง "นอกจังหวัด / ระดับประเทศ" ทางซ้าย
  - ย้ายตำแหน่งได้โดยแก้ช่อง "พื้นที่" เช่น `ต.ดู่ใต้ อ.เมืองน่าน` · ซูมแล้วจุดและชื่อไม่ขยายตาม ทำให้บริเวณที่แน่นแยกกันชัดขึ้น
  - ขอบเขตปกครอง: [OpenGISData-Thailand](https://github.com/chingchai/OpenGISData-Thailand) (ไฟล์ `nan_geo.json`)
- **มุมมอง "6 กลุ่มตามด้าน"** (ค่าเริ่มต้น): ทรัพยากรธรรมชาติ · การเกษตร · ส่งเสริมเศรษฐกิจ · การท่องเที่ยว · วัฒนธรรม · สุขภาพ
  - สีโหนด = ประเภทหน่วยงาน (ราชการ, อปท., องค์การมหาชน, สถาบันการศึกษา/วิจัย, มูลนิธิ/ประชาสังคม, เครือข่าย/กลุ่มชุมชน, วิสาหกิจ/เอกชน, วัด/ศาสนา, องค์กรระหว่างประเทศ)
  - วงประ = ด้านหลักของแต่ละหน่วยงาน · จุดเล็กใต้วงกลม = ด้านรอง · (+n) = จำนวนหน่วยงานที่มีด้านนั้นเป็นด้านรอง
  - เส้นทึบ = ยืนยันแล้ว · เส้นประ = รอยืนยัน
  - ยังสลับกลับไปดู "วง 3 ชั้น" ได้จากปุ่มมุมซ้ายบนของแผนภาพ
- ข้อมูลเพิ่มต่อโหนด: ด้าน (หลายด้าน), ประเภทหน่วยงาน, ระดับ, พื้นที่, สถานะการยืนยัน, หลักฐาน/แหล่งอ้างอิง
- โปรเจคใหม่ **"เครือข่ายป่าชุมชน + เกษตรอินทรีย์/ปลอดภัย น่าน"** (65 โหนด 115 เส้น) จากการสืบค้นเอกสารสาธารณะ — ข้อมูลส่วนใหญ่ยังเป็น *รอยืนยัน*; ชื่อบุคคลเป็นร่าง ต้องยืนยันและขอความยินยอมก่อนเผยแพร่ (PDPA)
- **อัปเดต 16 พ.ย. 2569:** เพิ่มวิทยาลัยชุมชนน่าน, ดร.พิมลพรรณ สกิดรัมย์, มูลนิธิรักษ์ไทย, มูลนิธิรักษ์ป่าน่านฯ และภาคี (RECOFTC, Wyss Academy, Local Alike, ChangeFusion, อพท.น่าน, มทร.ล้านนา น่าน ฯลฯ) + ประเด็นใหม่ 5 เรื่อง → 86 โหนด 181 เส้น (แหล่งอ้างอิง SRC18–35 อ่านจากข้อความย่อผลค้นหา ยังต้องยืนยัน)
- โหมดในเครื่อง: เมื่อ `data.json` มี `seedVersion` ใหม่ ข้อมูลตัวอย่างจะอัปเดตให้อัตโนมัติ (รายการที่ผู้ใช้เพิ่มเองยังอยู่)
- Excel/รายงานเพิ่มตาราง "Sector clusters" และสถานะ/หลักฐาน
- เก็บข้อมูลโหมดในเครื่องแยกจาก v1 (`nannetwork-v2`)

เว็บแอปแสดงเครือข่าย 3 วง (แนวคิดจาก food web → network analysis)

| วง | ประเภท | สี |
|---|---|---|
| ใน | ประเด็น (เช่น ความมั่นคงทางอาหาร ป่าชุมชน ชาวนา เด็กและเยาวชน สุขภาวะ ธุรกิจชุมชน) | ส้มอ่อน |
| กลาง | หน่วยงาน — คลิกเพื่อพิมพ์ "บทบาท" (แสดงเป็นการ์ดในแผงขวา) | เหลือง |
| นอก | บุคคล | เขียว |

- ความหนาเส้น = ระดับความสำคัญ 1–5 (ปรับได้ที่แผงขวา)
- แบ่งข้อมูลเป็นหลายโปรเจค (เมนูด้านบน) · ลิงก์ตรงไปโปรเจคด้วย `#p-<project-id>`
- แท็บ "วิเคราะห์เครือข่าย": strength, betweenness, ความครอบคลุมของประเด็น, หน่วยงานที่เชื่อมหลายประเด็น, โหนดที่ยังไม่เชื่อม
- สลับภาษา ไทย / EN (ปุ่มมุมขวาบน) · แต่ละรายการมีชื่อและบทบาทได้ทั้งไทยและอังกฤษ
- ดาวน์โหลดแยกตามโปรเจค (ใช้ภาษาที่เลือกอยู่):
  - **Excel (.xlsx)** 9 ชีต: สรุป, โหนด (+degree/strength/betweenness/closeness), เส้นเชื่อม (+ระดับความสำคัญ), บทบาทหน่วยงาน, ความครอบคลุมประเด็น, เมทริกซ์ ประเด็น×หน่วยงาน, เมทริกซ์ หน่วยงาน×บุคคล, อันดับศูนย์กลาง, ตัวเชื่อม
  - **รายงานสรุป (.html)** แผนภาพ + ตารางผลวิเคราะห์ → เปิดแล้วกด "พิมพ์ / บันทึกเป็น PDF"
  - **ภาพ PNG / SVG** พร้อมชื่อโปรเจคและคำอธิบายสัญลักษณ์
- ส่งออก/นำเข้า JSON

## โหมดการเก็บข้อมูล

1. **โหมดในเครื่อง** (ค่าเริ่มต้น, `config.js` = null) — โหลดตัวอย่างจาก `data.json`, ข้อมูลที่แก้ไขอยู่ในเบราว์เซอร์ของแต่ละคน
2. **โหมดเรียลไทม์ (Firebase)** — ทุกคนเห็นข้อมูลเดียวกัน, ผู้มีสิทธิ์ลงชื่อเข้าใช้ด้วย Google แล้วแก้ไขพร้อมกันได้
3. **Claude artifact** — ไฟล์เดียวกันเมื่อเปิดใน claude.ai จะใช้ฐานข้อมูลของ Claude อัตโนมัติ

## ตั้งค่าแก้ไขแบบเรียลไทม์ (Firebase, ฟรี ~10 นาที)

1. ไปที่ https://console.firebase.google.com → **Add project** (เช่น `nannetwork`) — ปิด Google Analytics ได้
2. **Build → Firestore Database → Create database** → เลือก location `asia-southeast1` → Production mode
3. แท็บ **Rules** → วางเนื้อหาไฟล์ `firestore.rules` → Publish
4. **Build → Authentication → Get started → Google → Enable**
   แล้วที่ **Settings → Authorized domains** เพิ่ม `tenrm.github.io`
5. ใน Firestore → **Start collection** `config` → document ID `editors` → field `emails` (array) ใส่อีเมลผู้มีสิทธิ์แก้ไข
6. **Project settings (⚙) → Your apps → Web (</>)** → Register app → คัดลอก `firebaseConfig`
7. แก้ไฟล์ `config.js` ใน repo:
   ```js
   window.NAN_FIREBASE_CONFIG = { apiKey: "...", authDomain: "...", projectId: "...", appId: "..." };
   ```
8. เปิดเว็บ → ฐานข้อมูลยังว่าง → ลงชื่อเข้าใช้ → กด **นำเข้าตัวอย่าง** (หรือ "นำเข้า JSON" จากไฟล์ที่ส่งออกจาก Claude)

> ค่า `apiKey` ของ Firebase ไม่ใช่ความลับ (ความปลอดภัยอยู่ที่ `firestore.rules`) จึงใส่ใน repo สาธารณะได้

## แบบสอบถามน่านฟอรั่ม (Google Form → แผนภาพแบบเรียลไทม์)

ผู้เข้าร่วมประชุมกรอก Google Form แล้วแผนภาพในโปรเจค **"น่านฟอรั่ม – ผลแบบสอบถามเครือข่าย (สด)"** อัปเดตเองทุก 30 วินาที

```
Google Form ──► Google Sheet (คำตอบ) ──► Apps Script Web app (JSON, ตัดเบอร์/อีเมลออก) ──► NanNetwork-v2 (ดึงทุก 30 วินาที)
```

1. เข้า https://script.google.com ด้วยบัญชีที่จะเป็นเจ้าของฟอร์ม → **New project** → วางโค้ดจาก `NanForum_FormFeed.gs` → Save
2. เลือกฟังก์ชัน `setup` → **Run** → อนุญาตสิทธิ์ → ดูลิงก์ฟอร์ม/ชีตใน Execution log
3. **Deploy → New deployment → Web app** · Execute as: **Me** · Who has access: **Anyone** → คัดลอก URL ที่ลงท้าย `/exec`
4. ทดสอบทันที: `https://tenrm.github.io/NanNetwork-v2/?feed=<URL /exec>#p-nan-forum-2569` · ใช้ถาวร: ใส่ URL ใน `config.js` (`window.NAN_FORM_FEED`)
5. ในวันประชุม กดปุ่ม **📝 แบบสอบถาม** มุมขวาบนเพื่อแสดง QR code ให้ผู้เข้าร่วมสแกน

การแปลงคำตอบเป็นแผนภาพ
- หน่วยงานของผู้ตอบ = โหนดหน่วยงาน (สี = ประเภท, ด้าน = ช่องที่ติ๊ก) และเชื่อมกับประเด็น "ด้าน…"
- หน่วยงานที่ร่วมงาน = เส้นทึบ (ยิ่งมีหลายคนระบุคู่เดียวกัน เส้นยิ่งหนา) · ด้านของหน่วยงานที่ถูกระบุ เดาจากคำในช่องประเด็น
- อยากร่วมงานในอนาคต = เส้นจุดสีเขียว · ต้องการข้อมูลจาก = เส้นประสีน้ำเงิน
- ชื่อผู้ตอบแสดงเฉพาะเมื่อติ๊กยินยอม; เบอร์โทร/อีเมล/LINE ไม่ออกจาก Google Sheet
- ชื่อหน่วยงานที่พิมพ์ต่างกัน รวมได้ที่ชีต `aliases` · ซ่อนคำตอบทดสอบ/สแปมได้ที่ชีต `hide`
- โปรเจคนี้รวมเครือข่ายที่สืบค้นไว้ (`nan-forest-organic` ใน data.json, ไม่รวมรายชื่อบุคคลร่าง) แล้วซ้อนคำตอบแบบสอบถามลงไป: ถ้าชื่อหน่วยงานที่ตอบตรงกับหน่วยงานเดิม (ชื่อเต็ม/ชื่อย่อในวงเล็บ/ส่วนก่อน " / ") จะรวมเป็นโหนดเดียว · ปิดได้ด้วย `baseProject: null` ใน config.js
- ทำงานในโหมดในเครื่อง (GitHub Pages); หน้า Claude artifact ดึงข้อมูลจากเว็บภายนอกไม่ได้
